# Gene(t#every)-Sorting_Hat(依頼のタグ付け・仕分け)
## 用語の説明
| 用語 | 説明 |
| --- | --- |
| タグ | ユーザーの依頼の分類。一覧は、同じフォルダの `Tag_List.md` にある |
| 指定するGene | 依頼のタグに当てはまる条件を持つGene(`Gene(t#タグの値)-…`)。`t#every` のGeneは、すべての依頼で指定される。`t#Developments` のGeneは、`Developments-` で始まるタグの依頼で指定される |

## 目的
- ローカルAIを育成するにあたって、普段のAI利用ではどのようなタイプがあるかをクラスタリングする

## 役割
- 依頼がどのタグに当てはまるかを都度分類して、活動報告に記録する
- タグに関連するGeneを指定して、動くようにする
- タグの数は必要最小限にして、`Tag_List.md` を更新する

## 手順
### プロセス1(入力整理)で、このGeneが指定されているとき
1. 整理した依頼ごとに、`Tag_List.md` の既存のタグのどれに当てはまるかを分類する
2. 既存のタグでどうしても振り分けられない場合は、既存のものと同じ形式・同じくらいの粒度で、新しいタグを作成してよい
   - とりあえずタグを作るということはせず、タグの数は必要最小限になるようにする
   - 作成したタグは、`Tag_List.md` に追記する
3. 依頼ごとのタグを、活動報告に記録する
4. 依頼のタグに当てはまるGeneを、`2-DNAs/` から探して、指定する(`x#` の無効なGeneは、指定しない)
5. 整理した依頼の一覧に、タグと指定したGeneを付けて、次のプロセスに渡す

### 睡眠(NREM睡眠)で、このGeneが指定されているとき
1. 活動報告に記録されたタグを集計し、AI利用のタイプを、タグごとの件数や傾向としてまとめる(クラスタリング)
2. まとめた結果を、KCBの記憶に入れる(睡眠の手順に従う)
