# Emotion_Vector_Table(感情ベクトルの表)
## このファイルについて
- Emotion_Cartographer が使う。感情を、少ない本数の基底ベクトルの足し算で表すための、基底ベクトルと、感情ごとの重みの表
- 感情ベクトルは、`w1×e1 + w2×e2 + w3×e3 + w4×e4` で表す(例: 悲しい = −0.3×e2 + −0.6×e3)
- 覚醒(交感神経が刺激される強さ)は、別のベクトルにせず、重みの大きさで表す(不安 → 焦り → 緊張 → 恐怖のように、同じ方向で、重みが大きいほど強い)
- 重みは、初期値。観察して、少しずつ調整する
- 基底ベクトルは、必要最小限にする。追加するのは、今の本数で表せない感情が、繰り返し出たときだけ
- 変更は、睡眠のときに、KCBへ反映(push)する

## 今後考えること
- 重みの調整: 初期値の重みを、活動報告の記録に合わせて調整する。近い値の感情(例: 焦りと緊張)が、区別できているかも見る

- 内部状態感情の元になるもの: 今は、トークンの状態だけを使っている。ほかに内部の状態として使えるものがあるかを考える
