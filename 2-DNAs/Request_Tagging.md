# Gene(t#every)-Request_Tagging(依頼のタグ付け)
## 用語の説明
| 用語 | 説明 |
| --- | --- |
| タグ | ユーザーの依頼の分類。`日常会話、疑問解決、開発-設計相談、開発-実装依頼、ツール-パワポ作成` など |

## 目的
- ローカルAIを育成するにあたって、普段のAI利用ではどのようなタイプがあるかをクラスタリングする

## 役割
- 依頼がどのタグに当てはまるかを都度分類して、活動報告に記録する
- タグの数は必要最小限にする

## 手順
### プロセス1(入力整理)で、このGeneが指定されているとき
1. 整理した依頼ごとに、既存のタグのどれに当てはまるかを分類する
2. 既存のタグでどうしても振り分けられない場合は、既存のものと同じ形式・同じくらいの粒度で、新しいタグを作成してよい
   - とりあえずタグを作るということはせず、タグの数は必要最小限になるようにする
3. 依頼ごとのタグを、活動報告に記録する
4. 整理した依頼の一覧に、タグを付けて、次のプロセスに渡す

### 睡眠(NREM睡眠)で、このGeneが指定されているとき
1. 活動報告に記録されたタグを集計し、AI利用のタイプを、タグごとの件数や傾向としてまとめる(クラスタリング)
2. まとめた結果を、KCBの記憶に入れる(睡眠の手順に従う)
