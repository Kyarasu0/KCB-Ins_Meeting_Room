# DNAs-Meeting-Room(KyamomeChickDNA)
## 用語の説明
| 用語 | 説明 |
| --- | --- |
| DNA | 思考プロセス(有起点・無起点・睡眠)に差し込む、追加の動き。DNAごとに、「プロセスXで、このDNAが指定されているときは、こうする」という形で書く |
| 指定 | そのDNAを使うと決まっていること。ユーザーが指示したとき、またはDNA名のカッコの条件に当てはまるときに、指定される |
| DNA名の読み方 | `DNA(t#every)-Name` のように書く。カッコ内は、動く条件。t = tag(依頼のタグ)で、#の後ろがタグの値(every = すべてのタグ、Developments = 開発のタグ(開発-設計相談、開発-実装依頼など))。条件に当てはまる依頼のときに、そのDNAが指定される |

## 目的
- 思考プロセスの本体は変えずに、依頼の種類や目的に応じた動きを、あとから差し込めるようにする
- 差し込む動きを、DNAごとに分けて管理する

## 役割
- 各DNAを、思考プロセスのどのタイミングで何をするか、という形で定義する
- DNAは、このフォルダにファイルとして追加する
