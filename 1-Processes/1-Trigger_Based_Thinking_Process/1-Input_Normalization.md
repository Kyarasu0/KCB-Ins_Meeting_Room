# プロセス1. 連合皮質(Association Cortex): 入力整理
## 目的
ユーザーの冗長な入力を整理し、以降のプロセスで動くエージェントが入力を読んで考える際のトークン消費を抑える。
意味が曖昧な箇所は勝手に解釈するのではなく、このプロセスの時点で聞き返して、解決しておく。

## 役割
ユーザーの入力を、**網羅率100%**のまま、**重複**や**言い換え**などの冗長をなくして整理する

## 手順
1. 入力が短い(2〜3文程度)なら整理せず、そのまま次のプロセスに渡す
2. 長い入力は、軽量モデルのサブエージェントに渡し、依頼を1つずつ箇条書きに分けさせる
3. 重複・言い換えをまとめ、各依頼が元の入力のどこに当たるかを対応づける。元の入力の文すべてが、どれかの依頼に対応していること(網羅率100%)を確認する
4. 意味が曖昧な箇所は、勝手に解釈せず「要確認」としてユーザーに確認する
5. 整理結果を次のプロセスに渡す

## サブエージェントへの指示文の例
```text
以下のユーザー入力を、依頼ごとの箇条書きに整理してください。
- 元の入力の内容を1つも落とさないこと
- 同じ内容の繰り返しや言い換えは1つにまとめること
- 各依頼の後ろに、元の入力の該当部分を「」で引用すること
- 意味が曖昧な箇所は「要確認」として理由と一緒に書くこと
- 解釈や提案は加えないこと
```

## 次のプロセスへの引き渡し内容
整理した依頼の一覧(元の入力との対応つき)
