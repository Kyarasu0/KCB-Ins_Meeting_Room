# プロセス4-2. 線条体(Striatum)・腹側被蓋野(VTA): 行動決定
## 用語の説明
| 用語 | 説明 |
| --- | --- |
| 報酬 | ここでの報酬とは、「ユーザーにどれほど喜んでもらえるか」であり、ドーパミンスコアで表す |
| ドーパミンスコア | 報酬の大きさを、1〜10(理由付き)で表した数値。神経解剖学では、腹側被蓋野(VTA)がドーパミンを分泌して、報酬の大きさや予測とのずれを伝える。ここでは、行動前に出すものを予測のドーパミンスコア(プロセス4-2)、作業終了後に実際の結果を受けて出すものを実際のドーパミンスコア(プロセス6)と呼ぶ。ドーパミンの分泌にあたるのは、実際のドーパミンスコアを出すプロセス6とし、予測との差が報酬の予測誤差として伝わる。実際のドーパミンスコアは、プロセス6でユーザーの反応やアンケートの回答を見て採点し、ユーザーに確認を取ってから記録する |
| 価値 | ここでの価値とは、利益とコストのことである |
| 利益 | 過程での利益のこと。報酬の「ユーザーにどれだけ喜んでもらえるか」のような結果的な良し悪しとは違い、「よりゴールに上手く行きやすいか(今後の保守運用やステップ数、ユーザーに理解しやすいシンプルさ)」などを示す。必要条件をどれだけ確実に満たすかも含む |
| コスト | 過程での不利益のこと。トークン消費・使うモデルの高さ・作業時間・失敗確率などを示す。既存機能を壊す可能性や取り返しがつくかといった危険性もここに含む |
| ユーザーの好み | KCBの記憶(内部海馬)にある、ユーザーの過去の好み(睡眠でまだ入っていないものは、meeting-roomの活動報告にある)。価値(利益・コスト)とは別に、行動候補がこれと合っているかを見る |

ファイルの位置説明・ファイルの手順説明は、プロセス4-1の用語の説明を参照する

## 目的
- プロセス4-1で作成した各行動候補を評価し、価値を比べて1つ選ぶ
- ここはプランの最終プロセスであるため、行動する前に、選んだ行動のファイルの位置説明とファイルの手順説明をユーザーへ提示して、承認を得る

## 役割
- 各行動候補の結果と報酬を行動前に予測し、価値を候補ごとに評価して、比較して1つ選ぶ
  - 線条体: 行動の「価値」を比較して選ぶ
  - 腹側被蓋野(VTA): 行動前に「報酬」を予測し、予測のドーパミンスコアを出す。このとき、過去の成功・失敗(内部海馬)を予測に反映する
- 選んだ行動を、ユーザーに提示して承認を得る

## 手順
1. プロセス4-1から受け取った行動候補ごとに、価値と報酬(予測のドーパミンスコア、理由付き)、より品質高くゴールを達成できそうかなどを予測する(保守運用や可読性、拡張性、クラウドAI特有の大量・必要ない情報の盛り込みをせず、シンプルさを担保できているか、また、必要条件をどれだけ満たせるか)
   - 候補が1つだけ、または生成されなかったときは、手順2〜4を省き、その行動の予測だけを行う
2. 各候補を、利益・コスト・ユーザーの好みごとに採点する
3. 内部海馬の `generalized-knowledge.md` に関連する教訓があれば、採点に反映する
4. 評価の結果、最も良い候補を選ぶ
   - 危険性が高い候補は、利益が大きくてもユーザーに確認してから選ぶ
5. 下の「行動前のプラン提示(後ほど補足)」を行い、ユーザーの承認を得る
   - 選んだ行動が、ユーザーの確認を要するもの(削除・push・外部への送信など)なら、その旨も明記して確認する
   - 大きな設計変更になる場合は、meeting-roomの `plans/` に計画書を作ってから進む
   - 承認が得られなかった場合は、その理由を聞いて、プロセス4-1に戻って行動候補を作り直す
6. 承認されたプランを、活動報告の「プラン」に書く(作業より先に書く)
   - 選んだ理由、予測した結果、予測のドーパミンスコア(理由付き)も書く(プロセス6で実際の結果・実際のドーパミンスコアと比べるため)
   - 実際のドーパミンスコアは、プロセス6で初めて出るため、ここでは書かない
7. プロセス5(行動)に渡す

## 行動前のプラン提示
ユーザーには、選んだ行動(ステップ)とその理由、予測した結果、予測のドーパミンスコア(理由付き)を提示する。
ファイルの作成・変更を伴う行動は、さらにファイルの位置説明とファイルの手順説明を提示し、実行前に必ず承認をもらう

## プロセス5への引き渡し内容
- プロセス2-1(1回目のDLPFC)で決めたゴール・必要条件
- プロセス2-2(ACC)で決めた努力量
- 承認されたプラン(ファイルの位置説明・ファイルの手順説明)
- 選んだ行動と、予測した結果・予測のドーパミンスコア、それぞれの理由
