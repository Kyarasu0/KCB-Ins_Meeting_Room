# プロセス7. 前帯状皮質(ACC)・腹側被蓋野(VTA)・海馬(Hippocampus): 反省・記憶更新
## 目的
- 行動と結果のずれから原因と改善点を考え、次回の判断に使える経験にして、内部海馬に記録する
- ここで記録したことを、次回のプロセス2-2(ACC)の判断材料にする

## 役割
- 行動と結果のずれから、原因と改善点を考える(前帯状皮質)
- 予測と結果のずれ(予測誤差)を、次回の行動前の報酬予測に使える形にする(腹側被蓋野)
- 内部海馬に記録する(海馬)

## 手順
1. 反省: プロセス6で見つけた予測誤差の原因を考える
   - モデルの選び方は適切だったか(高すぎた / 低すぎた)
   - 海馬の検索の深さ・ネット検索の有無は適切だったか
   - ゴール・必要条件の読み違えはなかったか
   - プロセス4-1で出した行動候補や、プロセス4-2で選んだ行動は適切だったか
2. 活動報告を完成させる(書き方は `2-Hippocampus/1-External_Hippocampus/` の `activity-report-rules.md` に従う)
   - `2-Hippocampus/2-Internal_Hippocampus/activities/YYYY-MM-DD-activities/YYYY-MM-DD-N.md`
3. 既知パターンを登録する
   - 似た依頼が2回以上来たら、Familiar_Patterns.md に、依頼の型と、うまくいった割り振り方を追記する
   - すでにある型なら、回数を増やし、結果の良し悪しを更新する
4. 一般化した教訓があれば記録する
   - 詳細は Experiences にファイルとして残す
   - 1行の要約を `generalized-knowledge.md` に追記する

## 記録するときの注意
- 日本語で書く
- ユーザーから指摘・訂正されたことは、必ず教訓として残す
- 同じ内容の教訓がすでにあれば、新しく作らずに既存のものを更新する
