# プロセス7. 前帯状皮質(ACC)・腹側被蓋野(VTA)・海馬(Hippocampus): 反省・記憶更新
## 目的
- 行動と結果のずれ、ユーザーのフィードバックから原因と改善点を考え、次回の判断に使える経験にして、活動報告に記録する(KCBの記憶への登録は、睡眠で行う)
- ここで記録したことを、次回のプロセス2-2(ACC)の判断材料や、プロセス4-2(VTA)の報酬の予測に使う

## 役割
- 行動と結果のずれ、アンケートのフィードバックから、原因と改善点を考える(前帯状皮質)
- 予測誤差(結果と報酬)を、次回の行動前の報酬の予測に使える形にする(腹側被蓋野)
- 活動報告に記録する(海馬)

## 手順
1. プロセス6から受け取った内容を確認する(必要条件ごとの判定とゴールの実現、調査の結果、アンケートの結果、実際のドーパミンスコア、予測誤差、トークンの状態)
2. 反省: プロセス6で出した予測誤差(結果と報酬)と、アンケートのフィードバックから、原因を考える
   - モデルの選び方は適切だったか(高すぎた / 低すぎた)
   - 海馬の検索の深さ・ネット検索の有無は適切だったか
   - ゴール・必要条件の読み違えはなかったか
   - プロセス4-1で出した行動候補や、プロセス4-2で選んだ行動は適切だったか
   - 報酬の予測誤差が大きいときは、ユーザーの好みや喜ぶ点の読み違えがなかったか
   - ゴールを実現できなかったときは、何が足りなかったか
3. 活動報告を完成させる(書き方は `3-Hippocampus/1-External_Hippocampus/` の `activity-report-rules.md` に従う)
   - 有起点の活動報告(`desk/activities/Trigger/YYYY-MM-DD-activities/YYYY-MM-DD-N_依頼の題名.md`。用語はオーケストレーターの用語の説明を参照)
   - アンケートの結果、実際のドーパミンスコア、トークンの状態も含める
   - 聞く内容の保留で、まだ聞けていない項目があれば、その旨も書く
4. ユーザーの好みを、活動報告に記録する
   - アンケートの回答や実際のドーパミンスコアから分かったユーザーの好みを書く(プロセス4-2の予測に使うため。KCBの記憶への登録は、睡眠で行う)
5. 既知パターンの候補を、活動報告に記録する
   - 似た依頼が2回以上来たら、依頼の型と、うまくいった割り振り方を書く(Familiar_Patterns.md への登録は、睡眠で行う)
   - すでにある型なら、結果の良し悪しも書く(実際のドーパミンスコアも使う)
6. 一般化した教訓があれば、活動報告に書く
   - Experiences や `generalized-knowledge.md` への登録は、睡眠で行う

## 記録するときの注意
- 日本語で書く
- ユーザーから指摘・訂正されたこと、アンケートで聞いたフィードバックは、必ず教訓として活動報告に残す
- 同じ内容の教訓がすでにKCBの記憶にあるときは、新しく書かずに、その旨を書く
