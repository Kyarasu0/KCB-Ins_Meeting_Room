# プロセス3. 背外側前頭前皮質(DLPFC): 記憶統合と方針評価
## 目的
- 記憶などの情報(内部海馬・外部海馬・ネット検索など)を統合し、このゴール・必要条件がそもそも正しいか、本当に達成できるか、作業が本当にスムーズに進みそうかを確かめる

## 役割
- プロセス2-2(ACC)で決めた努力量でプロセス2-1(1回目のDLPFC)で決定したゴール・必要条件に沿って、実際に各海馬やネットから情報収集し、それらの情報を統合する
- 統合した情報をもとに、ゴール・必要条件として設定されたものがそもそも適切か(プロセス2-1(1回目のDLPFC)で設定した内容が合っているか)と、努力量が適切か(プロセス2-2(ACC)で選んだ努力量が適切か)という2つの観点で、それぞれ評価する
- 足りなければ、プロセス2-1(1回目のDLPFC)またはプロセス2-2(ACC)に差し戻す

## 手順
1. 前プロセスで決定したモデル・種類のサブエージェントに、同じく前プロセスで決定した検索深度での各海馬の検索や思考量に基づいた思考を行う(独立した調査は並列で起動する)
2. 海馬の情報で足りなければ、ネット検索を行う(これも前プロセスで決定した検索深度に従う)
3. 集めた情報を見て、必要条件ごとに「満たせそう / 満たせなさそう / 不明」で整理する
4. 次の2つを評価する
   - ① ゴール・必要条件は正しいか(情報を統合してみて、プロセス2-1(1回目のDLPFC)の整理は適切だったか)
   - ② この努力量で良いものが出せるか(情報を統合してみて、プロセス2-2(ACC)の判断は適切だったか。「不明」が残る必要条件があれば、NGとする)
5. 判定に応じて進む先を決める
   - ①②ともにOK → プロセス4-1(行動候補生成)へ
   - ①がNG → 理由を添えてプロセス2-1(1回目のDLPFC)に差し戻す
   - ②がNG → 理由を添えてプロセス2-2(ACC)に差し戻す
   - 差し戻しが3回を超えた場合はユーザーに相談する

このループ(プロセス2-1・2-2への差し戻し)を差し戻しループ(小ループ)と呼ぶ

## 差し戻し方
- NGの理由を具体的に書く(例: 「必要条件2の根拠が見つからない」)
- 何を変えるべきかを書く(例: 「モデルを1段階上げる」「外部海馬を深く検索」)

## プロセス4-1への引き渡し内容
- プロセス2-1(1回目のDLPFC)で決めたゴール・必要条件の一覧
- プロセス2-2(ACC)で決めた努力量
- 統合した情報(必要条件に対応)
