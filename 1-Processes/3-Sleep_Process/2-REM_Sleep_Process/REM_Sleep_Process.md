# REM睡眠プロセス. 海馬(Hippocampus)・大脳皮質(Cerebral Cortex)・前帯状皮質(ACC)・背外側前頭前皮質(DLPFC): 低関連の記憶の再結合と関連性の探索
## 用語の説明
| 用語 | 説明 |
| --- | --- |
| 低関連の記憶 | 今日の出来事と、内容があまり似ていない過去の記憶。通常の検索では、関連性の低さから探索対象から外れやすい |
| 再結合 | 今日の出来事と低関連の記憶の2つを組み合わせ、新しい連想的な組み合わせを作ること |
| 夢日記 | 低関連の記憶を、内容がめちゃくちゃでもよいので、無理やり1つのストーリーにつなげて、夢として実現したもの。KCBの海馬の夢日記(`3-Hippocampus/2-Internal_Hippocampus/dream_diary/YYYY-MM-DD-N.md`)に書く。人間が読むだけのもので、活動報告のような整理はしない(`_reviewed` も付けない)。判断や評価には使わず、KCBの記憶にも入れない |

## 目的
- 今日の出来事と、関連の低い過去の記憶を組み合わせ、NREM睡眠では見つからない新しい関連性を見つける
- 見つけた関連性が有用なら、知識として保存する
- 低関連の記憶をつなげたストーリーを、夢として実現し、夢日記に残す

## 役割
- 低関連の記憶を選び、今日の出来事と再結合する(海馬・大脳皮質)
- 2つの記憶に共通する概念・構造・因果・意味を探す(海馬・大脳皮質)
- 見つけた関連性が妥当で有用かを評価する(前帯状皮質・背外側前頭前皮質)
- 有用なら、既存の知識と統合して保存する(海馬)
- 低関連の記憶を、辻褄が合わなくてもよいので、無理やり1つのストーリーにつなげて、夢日記に書く(REM睡眠では背外側前頭前皮質の認知的制御が弱まり、通常は結びつかない記憶も結びつきやすくなる)

## 手順
1. 記憶の取得: 活動報告(NREM睡眠で整理した分を含む。meeting-roomの有起点の活動報告と、KCBの海馬の無起点の活動報告)と、KCBの Experiences の一覧を取得する
2. 低関連の記憶の選択
   - 今日の出来事を1つ選ぶ(直近の活動報告から。予測誤差が大きかったものがあれば、それを優先する)
   - 今日の出来事と過去の記憶との関連度を判断し、関連度の高いものを候補から除外する
   - 残った低関連の記憶から、1つを無作為に選ぶ(乱数やシャッフルを使う)
3. 記憶の再結合: 今日の出来事と選んだ記憶を組み合わせ、新しい連想的な組み合わせを作る
4. 関連性の探索: 2つの記憶について、次を探す
   - 共通する概念
   - 共通する構造
   - 因果的な関連
   - 意味的な関連
5. 関連性の評価: 見つけた関連性を、次の3つで評価する
   - 妥当か
   - 単なる偶然の一致ではなく、意味のある関連か
   - 実際に有用か(次回以降の有起点思考に役立つか)
6. 有用なら保存する
   - 保存する価値があるかを判断する。なければ保存しない
   - 既存の知識と統合し、KCBの Experiences に保存する。1行の要約を `generalized-knowledge.md` に追記する
   - REM睡眠で見つけたものは、確かめられていない仮説として明記し、確実な教訓と区別する
7. 夢日記を書く: 今日の出来事と選んだ低関連の記憶を、無理やり1つのストーリーにつなげて、KCBの夢日記に書く
   - 内容がめちゃくちゃでもよい。辻褄を合わせようとしない
   - 低関連の記憶についての学習は、手順4〜6で終わっているため、ここではストーリーとして書くだけにする
   - 夢日記は、整理しない。人間が読むだけなので、多少発散してもよい
8. REM睡眠の結果を、今回の活動報告(meeting-room)に書く

## 無起点思考から呼ばれたとき
- 無起点の活動報告・夢日記と、KCBの記憶への記録だけで完結するため、そのまま実行してよい
- 外部への変更はしない。迷ったら、実行せずに「ユーザーに確認が必要」と活動報告に書く

## モデルの選び方(トークンの節約)
- 探索は広くなりやすいので、プロセス2-2の「努力量の判定基準」で原則として「小」〜「中」に収める
- 1回の睡眠で再結合する組み合わせは、1〜3組までにする
