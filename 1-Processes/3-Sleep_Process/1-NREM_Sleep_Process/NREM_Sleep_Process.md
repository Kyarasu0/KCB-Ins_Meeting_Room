# NREM睡眠プロセス: 経験の整理と長期記憶化
## 用語の説明
| 用語 | 説明 |
| --- | --- |
| 睡眠 | 活動報告から経験知識を整理し、散らかった情報を片付ける処理。NREM睡眠、REM睡眠の順に行う |
| NREM睡眠 | 起きている間に溜まった活動報告を再生し、整理して長期記憶にする。この手順書が担当する |
| REM睡眠 | NREM睡眠のあとに行う。今日の出来事と関連の低い記憶を組み合わせ、新しい関連性を探す |
| `_reviewed` | 整理済み(目を通した印)として、活動報告のファイル名に付ける |

## 目的
- 活動報告に溜まった経験から、どの作業にも使えそうなパターンを経験知識として整理し、次回以降の判断に使えるようにする
- 不要なブランチなどの散らかった情報を片付け、間違った記憶や古くなった記憶を直す

## 役割
- 未整理の活動報告を再生し、既知のパターンか新しいパターンかを仕分ける
- 繰り返し現れるパターンから、一般化した教訓を作り、圧縮して保存する
- 過去の処理・行動戦略を評価し、成功・失敗を次回に活かす
- 内部海馬の構造を、速く探せるように整える

## 睡眠が必要だと判断する条件
次のどれかに当てはまったら、作業の開始時か終了時に睡眠を行う
- `_reviewed` が付いていない活動報告が5件以上ある
- 内部海馬の `sleep-log.md` を見て、前回の睡眠から7日以上たっている
- 作業中に、リモートで消えたローカルブランチを見つけた
- ユーザーから整理を頼まれた

作業の途中では睡眠しない。実行する前に、ユーザーに「整理してよいか」を一言確認する

## 手順
### 経験の整理
1. 再生・振り返り: `_reviewed` が付いていない活動報告を読む
   - 対象: `2-Hippocampus/2-Internal_Hippocampus/activities/`
2. 既存・新規の仕分け: 活動報告の内容を、Familiar_Patterns.md・`generalized-knowledge.md`・Experiences と比べる
   - 既知のパターンなら、発生回数を増やす
   - 未知のパターンなら、新しい記憶・知識として登録する
3. 重要度の調整: 経験の重要度を見直し、優先度を調整する
   - ユーザーから指摘・訂正されたこと、同じ失敗の繰り返し、影響が大きかったことは、優先度を上げる
4. パターン抽出・圧縮: 繰り返し現れるパターンから共通する情報を抜き出し、一般化した教訓にする
   - 自分の判断ミス・改善点 → Experiences の自己反省のフォルダ
   - ユーザーとのやり取りで学んだこと → Experiences のコミュニケーションのフォルダ
   - 1行の要約を `generalized-knowledge.md` に追記し、重複する教訓はまとめる
   - 個々の活動報告は削除しない
5. 戦略更新: 過去の処理・行動戦略を評価し、成功・失敗を見分ける
   - Familiar_Patterns.md の依頼の型と割り振り方を更新する
   - プロセス2-2の判定基準などを変えたほうがよいと分かったときは、直接書き換えず、改善案としてユーザーに提案する
6. 整理し終えた活動報告のファイル名に `_reviewed` を付ける
7. 記憶の構造整理: Experiences を、内容の近いもの同士でグループ分けし、件数が多いフォルダは小さく分ける(階層分け)
   - ファイルを移したら、索引と参照を更新する
   - 失敗したら、移したファイルを元に戻し、原因を活動報告に書く。失敗しても睡眠全体は止めず、REM睡眠に進む

### 片付け(不要な情報の削除)
8. `git fetch --prune` でリモートの状態を最新にする
9. `git branch -vv` で、上流が `[gone]` になっているローカルブランチを探す
10. 見つけたブランチを `git branch -d` で削除する
   - 今いるブランチは削除しない
   - 未マージで `-d` では消せないものは消さず、ユーザーに確認する
11. 間違っていると分かった記憶や、古くなった記憶を削除・修正する

### 記録
12. 整理した内容を、内部海馬の `sleep-log.md` に追記する
13. 整理した内容の要点をユーザーに報告する

## 無起点思考から呼ばれたとき
- ユーザーに確認できないため、「実行前の確認」は省き、片付け(手順8〜11)はしない
- 手順1〜7(経験の整理)と手順12(記録)だけを行う。手順13の報告は、活動報告に書く
- 詳細は `2-Non_Triger_Based_Thinking_Process/` の `Non_Trigger_Based_Thinking_Process.md` を参照
